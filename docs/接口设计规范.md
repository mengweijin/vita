# 接口设计规范

## 操作型 API 设计

明确操作动词。结构遵循以下整体规则：

- `/<模块名称>/<实体类名称>/<动作>/[<其它>]/<路径参数>`

常用动作词：

- list
- page
- query
- create
- update
- remove
- import
- export
- enable
- disable
- set
- reset
- add
- change
- release
- revoke
- generate

```shell
# 查询
@GetMapping("/system/user/list")                            // 查询所有用户
@GetMapping("/system/user/page")                            // 分页查询用户
@GetMapping("/system/user/list/terminalInfo")               // 查询用户在线的终端列表

@GetMapping("/system/user/query/{id}")                      // 根据主键 ID 查询 User 对象
@GetMapping("/system/user/query/bo/{id}")                   // 根据主键 ID 查询 UserBO 对象
@GetMapping("/system/user/query/nickname/{id}")             // 根据主键 ID 查询用户昵称

@GetMapping("/system/user/query/by/username/{username}")    // 根据用户名查询
@GetMapping("/system/user/query/by/role/{roleId}")          // 根据角色 ID 查询

# 操作
@PostMapping("/system/user/create")                     // 创建用户
@PostMapping("/system/user/update")                     // 更新用户

@PostMapping("/system/user/import/excel")               // 批量导入
@PostMapping("/system/user/export/excel")               // 批量导出

@PostMapping("/system/user/update/basicInformation")    // 更新用户基础信息
@PostMapping("/system/user/generate/totpQrcode")        // 生成 totp 二维码

@PostMapping("/system/user/remove/{ids}")               // 删除用户
@PostMapping("/system/user/enable/{id}")                // 启用用户
@PostMapping("/system/user/disable/{id}")               // 禁用用户
@PostMapping("/system/user/change/password")            // 修改密码
@PostMapping("/system/user/reset/password")             // 重置密码
@PostMapping("/system/user/set/avatar")                  // 设置图像
@PostMapping("/system/user/set/roles")                   // 设置角色
```
